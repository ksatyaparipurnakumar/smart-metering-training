HOW TO OPEN
Double-click index.html (Chrome or Edge). Keep the "assets" folder next to it.
Internet is needed only for the fonts and the 3D model; everything else works offline.

HOW TO SHARE
- Send Smart_Metering_Study_Material.zip (one file). Participants unzip and open index.html.
- Or host the folder on GitHub Pages: upload index.html and the assets folder to a repository,
  then Settings > Pages > Deploy from branch (main, root).
